# Dataset

This project uses the [Jigsaw Toxic Comment Classification Challenge](https://www.kaggle.com/competitions/jigsaw-toxic-comment-classification-challenge)
dataset from Kaggle (~160K Wikipedia talk-page comments, multi-label
toxicity annotations). It isn't committed to this repo — it's a few
hundred MB and freely available from Kaggle directly.

## Getting the data

1. Accept the competition rules on the
   [Kaggle competition page](https://www.kaggle.com/competitions/jigsaw-toxic-comment-classification-challenge/rules)
   (required once, even though the competition is closed — this is how
   Kaggle gates the download).
2. Install and configure the Kaggle CLI if you haven't already:
   ```bash
   pip install kaggle
   # then place your API token at ~/.kaggle/kaggle.json
   # (Kaggle account settings -> Create New Token)
   ```
3. Download and unzip into this folder:
   ```bash
   cd data
   kaggle competitions download -c jigsaw-toxic-comment-classification-challenge
   unzip jigsaw-toxic-comment-classification-challenge.zip
   unzip train.csv.zip && unzip test.csv.zip && unzip test_labels.csv.zip
   ```

You should end up with `train.csv` (used for everything in this
project — it has the actual toxicity labels; the competition's
`test.csv`/`test_labels.csv` are for the Kaggle leaderboard submission
and aren't used here, since our own stratified train/val/test split is
carved out of `train.csv`).

Everything else (`jigsaw_processed.csv`, `covert_toxic_subset.csv`,
the trained model `.pkl` files, etc.) is generated by running the
notebook — nothing else needs to be downloaded by hand.
